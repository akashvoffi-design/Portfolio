## 🎯 Design Direction & Style

### Overall Aesthetic
- **Theme**: Modern, Dark, Professional yet Playful
- **Mood**: Tech-forward, Creative, Trustworthy
- **Approach**: Minimalist with Strategic Visual Impact
- **Era**: Contemporary (2024-2026 design trends)

### Key Design Characteristics
- ✨ **Dark Mode First** - Dark navy/black backgrounds
- 🎨 **Bold Accent Colors** - Cyan and emerald pop against dark
- 📐 **Geometric Elements** - Tilted cards, floating layouts
- 🌊 **Gradient Overlays** - Smooth color transitions
- 3️⃣ **3D Effects** - Tilted/rotated cards with depth
- 📸 **Scattered Images** - Floating photos with shadows
- ✍️ **Bold Typography** - Large, confident heading text
- 🎭 **Playful Spacing** - Non-grid, artistic layouts

## 🏗️ Component Styles

### 1. Hero Section
```
Background:          #0A0E27 (dark navy)
Gradient Overlay:    Cyan (#00D9FF) at bottom, fading to transparent
Hero Title:          Bold, white, 56-72px
Hero Subtitle:       Gray (#A0A0A0), 18-24px
CTA Button:          Cyan background (#00D9FF), dark text, rounded
Profile Image:       Circular or slightly tilted, with subtle shadow
Layout:              Center-aligned with floating elements
Height:              80-100vh (full viewport)
```

### 2. 3D Card Components
```
Card Background:     Semi-transparent dark (#1A1F3A with 0.7 opacity)
Card Border:         Subtle cyan (#00D9FF) glow/border
Card Rotation:       15-25 degree tilt on X or Y axis
Card Shadow:         Deep shadow for depth effect
Inner Content:       Text, images, icons overlapping
Hover Effect:        Slight scale up, enhanced glow
Example Cards:
  - "Where I help" (Sales, Growth, Product)
  - "How I got here" (Personal image)
  - "Life off-screen" (Lifestyle images)
```

### 3. Section Headers
```
Font Size:           48-64px
Font Weight:         Bold (700-900)
Color:               White (#FFFFFF)
Sub-text:           Gray (#A0A0A0), smaller
Alignment:          Left-aligned or centered
Bottom Border:      Cyan accent line (optional)
Spacing:            Large top/bottom padding (60-100px)
```

### 4. Text Content Areas
```
Body Text:           Light gray (#E5E5E5), 16-18px
Line Height:         1.6-1.8 for readability
Maximum Width:       600-800px for readability
Text Color:          #E5E5E5 (main), #A0A0A0 (secondary)
Emphasis:            Cyan (#00D9FF) for highlights
```

### 5. CTA Buttons
```
Primary Button:
  - Background: Cyan (#00D9FF)
  - Text: Dark navy (#0A0E27), bold
  - Padding: 14-16px × 32-40px
  - Border Radius: 8-12px
  - Hover: Brighter cyan, slight scale
  - Font Size: 16-18px

Secondary Button:
  - Background: Transparent
  - Border: 2px cyan (#00D9FF)
  - Text: Cyan (#00D9FF)
  - Hover: Fill with cyan
```

### 6. Images & Visual Elements
```
Image Treatment:    Scattered, floating, tilted placement
Image Shadows:      Dark drop shadows for depth
Image Borders:      Subtle cyan glow or border
Image Rotation:     -5 to +10 degree rotation
Image Overlap:      Can overlap other elements
Parallax:           Subtle parallax on scroll
Filter:             Optional slight color overlay
```

### 7. Gradient Section Dividers
```
Height:              80-120px
Gradient:            Cyan → Dark Navy (horizontal or diagonal)
Opacity:             0.3-0.5 for subtle effect
Position:            Between major sections
Animation:           Subtle fade-in on scroll
```

### 8. Statistics / Metrics Section
```
Number Style:        Large, bold (36-48px), cyan accent
Label:               Gray text below numbers
Icons:               Simple, monochromatic, 24-32px
Layout:              3-column grid with breathing room
Background:          Dark with subtle card styling
```

### 9. Testimonial Cards
```
Background:          Semi-transparent dark (#1A1F3A)
Border:              Cyan left border (4-6px)
Text Color:          Light gray (#E5E5E5)
Author:              Small, gray text
Quote Mark:          Large, cyan accent (#00D9FF)
Padding:             24-32px
```

### 10. Project/Portfolio Cards
```
Image:               Large, featured image
Title:               Bold, white, 24-28px
Description:        Gray text, 14-16px
Tags:                Cyan badges, dark background
CTA Link:            "View Project" in cyan
Hover:               Slight lift, enhanced shadow
Layout:              Card with image on top or side
```

## 📐 Layout & Spacing

### Page Structure
```
Header/Navigation:   Fixed or sticky, minimal, dark

Content Sections:    Variable height, 600-800px each
Spacing Between:     60-100px padding top/bottom

```
Base Unit:           16px
Small:               8px, 12px

```
Desktop:             12-column grid, 1200px max-width
Tablet:              8-column grid, 768px
Mobile:              4-column grid, 375px
Gutter:              24-32px between columns
```

## 🎬 Animation & Interactions

### Scroll Animations
```
Fade In:             Elements fade in as they scroll into view
Slide Up:            Content slides up with staggered timing
Parallax:            Background moves slower than foreground
Rotate In:           Cards rotate into view
Scale In:            Elements grow from small to full size
Duration:            0.6-1.2 seconds
Easing:              Ease-out-cubic or similar smooth easing
```

### Hover Effects
```
Cards:               Scale 1.02-1.05, enhanced shadow
Buttons:             Color shift, slight scale
Images:              Slight zoom, brightness adjust
Links:               Underline appears/fades in
Duration:            0.3-0.4 seconds
```

### 3D Effects
```
Perspective:         1000px
Rotation:            Subtle tilt on mouse move
Depth:               Multiple layers with different Z-index
Glitch Effect:       Optional subtle RGB shift
Lighting:            Simulated light source from top-left
```

### Micro-interactions
```
Link Hover:          Cyan underline animation
Button Press:        Slight inward shadow
Form Focus:          Cyan border glow
Scroll Indicators:   Subtle dots or lines
Loading:             Animated gradient or spinner
```

## 📱 Responsive Design

### Breakpoints
```
Mobile:              < 768px (phones)
Tablet:              768px - 1024px
Desktop:             1024px - 1440px
Large Desktop:       > 1440px
```

### Mobile Adaptations
```
Hero Title:          36-44px (from 56-72px)
Section Padding:     32-40px (from 60-100px)
Card Rotation:       Reduced or disabled for touch
3D Effects:          Simplified or disabled
Images:              Full width with proper spacing
Buttons:             Larger touch targets (48px minimum)
Font Sizes:          Slightly smaller for readability
Gradients:          More subtle (lower opacity)
```

## 🎨 Color Usage Guidelines

### Where to Use Each Color

| Color | Usage | Examples |
|-------|-------|----------|
| **Cyan (#00D9FF)** | Primary accent, CTAs, borders, glows | Buttons, highlights, section accents |
| **Emerald (#00C896)** | Secondary accent, growth highlights | Success states, alternative CTAs |
| **Dark Navy (#0A0E27)** | Primary background | Hero, main sections |
| **Dark Overlay (#1A1F3A)** | Cards, panels, transparency | Card backgrounds, modals |
| **Butter Yellow (#F5E6B3)** | Warm accent, visual pop | Icon backgrounds, badge accents |
| **Light Gray (#E5E5E5)** | Primary text | Body content, headings |
| **Medium Gray (#A0A0A0)** | Secondary text | Subtitles, descriptions |

### Contrast Ratios (WCAG AA minimum)
```
Light Gray (#E5E5E5) on Dark (#0A0E27):    16.8:1 ✓ Excellent
Cyan (#00D9FF) on Dark (#0A0E27):          5.2:1 ✓ Good
Medium Gray (#A0A0A0) on Dark (#0A0E27):   6.1:1 ✓ Good
```

## 📸 Image Specifications

### Profile Image
```
Dimensions:          Circular or square, 400x400px minimum
Format:              JPG or WebP (optimized)
File Size:           < 300KB
Background:          Transparent or dark neutral
Effect:              Consider slight vintage or warm filter
Multiple Angles:     3-5 different angle shots available
Quality:             High-res, professional, well-lit
```

### Project Images
```
Dimensions:          1200x800px or 1920x1080px
Format:              JPG or WebP
File Size:           < 500KB each
Aspect Ratio:        16:9 or 4:3
Quality:             High resolution, clear details
Thumbnails:          400x300px versions for cards
```

### Section Background Images
```
Dimensions:          Full width (1920px minimum)
Format:              JPG or WebP
File Size:           < 1MB per image
Opacity:             Used with dark overlay
Effect:              Subtle, doesn't distract from text
```

## 🎬 Animation Presets

### Fade In
```
Duration: 0.8s
Delay: 0.2s
Easing: ease-out
Opacity: 0 → 1
```

### Slide Up
```
Duration: 0.8s
Delay: varies by item
Easing: ease-out-cubic
Transform: translateY(40px) → translateY(0)
```

### Rotate In
```
Duration: 1s
Easing: ease-out-cubic
Transform: rotateY(90deg) → rotateY(0)
Perspective: 1000px
```

### Parallax Scroll
```
Speed: 0.5 (background)
Easing: linear
Movement: Y-axis (vertical)
Breakpoint: Desktop only (disable on mobile)
```
